Exercises

Exercise 6: Clap Switch

INMP441 • Toggle • LED

1 clap → GREEN LED (D6) ON / 2 claps within 1s → OFF. Uses INMP441 I2S mic (device 1, 48kHz). Adaptive noise baseline, spike detection, 1.5s startup warmup, and re-arm gate prevent false triggers.

Input: INMP441 I2S mic (device 1, 48kHz) Output: GREEN LED (D6)
Ready

Exercise 7: Voice Relay & Servo Control

INMP441 • VOSK • Relay • Servo

VOSK speech recognition controls relays (D27, D10, D26, D25) and servo (D12). Commands: "open/close relay", "open/fast/stop servo", "open/close all". Resamples 48kHz mic to 16kHz for VOSK.

Input: INMP441 I2S mic (device 1, 48kHz) Output: Relays (D27, D10, D26, D25), Servo (D12)
Ready

Exercise 8: Noise Level Classifier

INMP441 • 3 States • LEDs

Real-time noise classification using INMP441 (device 1, 48kHz). GREEN (D6) = quiet, ORANGE (D13) = moderate, RED (D5) = noisy. Adaptive auto-thresholds and 160ms anti-flicker hold prevent rapid LED switching.

Input: INMP441 I2S mic (device 1, 48kHz) Output: Red (D5), Green (D6), Orange (D13)
Ready

Exercise 9: Voice Activated System

INMP441 • LCD • Buzzer

Detects sustained voice (≥200ms above adaptive threshold). LCD shows "VOICE DETECTED" via TCA9548A mux. Buzzer (D21, active-low) beeps twice per trigger with 1.2s cooldown. Falls back gracefully if LCD unavailable.

Input: INMP441 I2S mic (device 1, 48kHz) Output: LCD (I²C mux CH0), Buzzer (D21)
Ready

Exercise 10: Loud Sound Alert

INMP441 • Buzzer • LEDs • LCD

Triggers 2s alarm (buzzer + blinking RED D5 + ORANGE D13) when loud sound is held ≥120ms above adaptive threshold. 1.5s cooldown between alarms. Optional LCD shows "LOUD SOUND! ALERT!" via I²C mux.

Input: INMP441 I2S mic (device 1, 48kHz) Output: Buzzer (D21), Red (D5), Orange (D13), LCD (optional)
