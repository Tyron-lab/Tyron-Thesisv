I²C Sensors & Integration

Exercises

Exercise 11: BMP280 on LCD

BMP280 • TCA9548A • LCD

Reads BMP280 (mux CH2, auto addr 0x76/0x77) every 2s. Displays temperature (°C) on line 1 and pressure (kPa) on line 2 of LCD (mux CH0). Gracefully continues without LCD if unavailable.

Input: BMP280 (I²C mux CH2) Output: LCD (I²C mux CH0, addr 0x27)
Ready

Exercise 12: MPU6050 Motion Status

MPU6050 • TCA9548A • Motion

Reads MPU6050 (mux CH1, auto addr 0x68/0x69) every 250ms. Classifies as STILL or MOVING using accel delta >1.2 m/s² or gyro >25 dps. LCD shows motion status + debug values (aΔ and gyro mag).

Input: MPU6050 (I²C mux CH1) Output: LCD motion status (I²C mux CH0)
Ready

Exercise 13: Formatted Multi-Sensor Display

DHT11 • BMP280 • Gas • LCD

Cycles every 3s: Screen 1 → DHT11 (D4) T/H, Screen 2 → BMP280 (mux CH2) T/P in kPa, Screen 3 → MQ Gas (D23 DO) level % + OK/ALERT. Gas alert at ≥30%. All displayed on LCD via I²C mux CH0.

Input: DHT11 (D4), BMP280 (mux CH2), MQ Gas (D23) Output: LCD cycling screens (I²C mux CH0)
Ready

Exercise 14: BMP280 + MPU6050

BMP280 • MPU6050 • TCA9548A

BMP280 (mux CH2) and MPU6050 (mux CH1) share I²C bus. Cycles 2.5s: BMP screen (T/P in kPa) then MPU screen (STILL/MOVING + A & G values). Properly deinits I²C and disables all mux channels on exit.

Input: BMP280 (mux CH2), MPU6050 (mux CH1) Output: LCD cycling (I²C mux CH0)
Ready

Exercise 15: I²C Device Check

TCA9548A • I²C Scan • LEDs

Probes LCD (CH0), BMP280 (CH2), MPU6050 (CH1) every second via TCA9548A. GREEN (D6) = all present, RED (D5) = any missing, ORANGE (D13) blinks while checking. LCD shows exact missing sensor(s). 500ms timeout prevents bus hang.

Input: I²C bus scan (mux CH0/1/2) Output: Green (D6), Red (D5), Orange (D13), LCD
